# Charter

## Purpose

Full Cycle Kubernetes is a hands-on portfolio and learning showcase for core
Kubernetes concepts using a small Go web application, a local Kind cluster,
and progressive manifests for workload and service patterns.

## Audience

- Technical reviewers assessing practical Kubernetes and container workflow
  knowledge.
- Learners following a reproducible local path through pods, ReplicaSets,
  Deployments, Services, upgrades, and rollbacks.

## Success measures

- The learning path explains each foundational Kubernetes concept clearly.
- A reviewer can understand how the Go workload, Kind cluster, and resources
  relate without treating the repository as an active production service.
- Cluster-management tools are used only in an intentional, disposable local
  environment.

## Ownership and cadence

The repository owner prioritizes work through GitHub Issues and the personal
portfolio Project. Update this charter when the showcase purpose, audience, or
supported operating posture changes.
